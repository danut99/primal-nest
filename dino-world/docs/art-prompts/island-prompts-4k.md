# High-resolution island terrain

Generated with the approved Image API CLI route, gpt-image-2, high quality, native 3456 x 2304 pixels. No upscaling. Flat magenta background removed with the imagegen chroma-key helper (corner sampling, tolerance 40, edge contract 1, feather 0.5); converted to WebP quality 92 without resizing. Prior artwork remains alongside these versioned assets. Logical map dimensions are independent of source-image resolution.

Sharply defined silhouette suitable for background removal. Theme: Main expedition settlement island: broad lush grass and warm sandy building ground, mostly clear central plateau, small prehistoric palms, ferns and a few fossil stones at rear border. Welcoming green and ochre colors. Extra wide open usable land for six separate buildings to be added later.
