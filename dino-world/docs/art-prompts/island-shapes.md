# Island silhouettes: six distinct shapes

Same pipeline as `island-prompts-4k.md`: gpt-image-2, high quality, native 3456 x 2304 pixels, no upscaling. Flat magenta background removed with the chroma-key helper (corner sampling, tolerance 40, edge contract 1, feather 0.5). Saved as WebP quality 92 without resizing.

The goal is a silhouette you can recognise from far away on the map. Each island has a different shape, but all six keep the same camera, light, scale and style so they still belong to one world.

## Hard constraints (all six)

- **Walkable plateau zone.** The game places up to 10 dinosaurs at fixed points (`habitatSpot` in `src/screens/WorldScreen.tsx`). Those points span **20–80 % of canvas width** and **35–85 % of canvas height**. That rectangle must be continuous flat walkable ground on every island. The shape varies only outside it: rims, spurs, the underside, detached fragments, overhangs.
- **Same footprint.** The island spans about 85–92 % of canvas width so all islands read at the same scale on the map.
- **Same camera and light.** Elevated isometric camera at about 35 degrees, warm light from upper left. Without this the map looks like a collage.

## After generating

1. Save as `public/world/<name>-island-4k.webp` (fire, water, earth, jungle, ice, storm). Keep the old file next to it if you want to compare.
2. Run `python scripts/world-images.py`. It regenerates the 2K, the grey locked version and the shadow.
3. Check in the game:
   - dinosaurs stand on ground, not on rocks or in the void;
   - the island looks the same size as the others.

   If dinosaur positions need adjusting for one shape, add a `layout` (spots and walking area) for that island in `src/world/islands.ts`, like the water crescent.
